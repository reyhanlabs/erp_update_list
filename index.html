How it works

  1. App loads the project list from /api/redmine-projects — a Vercel proxy that fetches Redmine projects with your API key.
  2. Select a project from the dropdown (auto-saved, defaults to Zahir ERP if available).
  3. Preview to see which issues will be synced.
  4. Click Sync Now — new issues become a new Update Plan named after the project.
Setup required. Make sure REDMINE_API_KEY is set in Vercel, and files api/redmine.js + api/redmine-projects.js exist in your repo.
