Memulai

Login & akun

Masuk dengan Sign in with Google supaya plan dan summary yang sama muncul di laptop dan HP. Fitur yang mengambil data Redmine dan mengirim Telegram hanya bisa dipakai oleh akun Google yang sudah didaftarkan pemilik aplikasi.

Continue as guest tetap bisa dipakai untuk mencatat plan dan summary, tapi datanya terikat ke perangkat itu saja dan menu Redmine/Telegram tidak aktif.

Pindah dari guest ke Google? Login Google dari perangkat yang sama. Data guest otomatis ikut dipindahkan ke akun Google kamu.

Workspace tim

Workspace membuat satu tim melihat plan dan summary yang sama secara realtime. Semua orang yang bergabung ke kode workspace yang sama berbagi data.

  1. Satu orang membuka Settings → Team Workspace, lalu klik Copy code.
  2. Rekan tim menempelkan kode itu di kolom workspace, lalu klik Join.
  3. Untuk kembali ke data pribadi, klik Use personal.
Kode workspace berfungsi seperti kata sandi. Bagikan hanya ke anggota tim, dan jangan memakai kode pendek yang mudah ditebak.

Tampilan & sidebar

Pilih tema Light, Dark, atau Auto (mengikuti pengaturan perangkat) dari tombol di kanan atas atau dari Settings → Appearance.

Tombol ☰ di kiri judul halaman mengecilkan sidebar menjadi deretan ikon supaya area kerja lebih lebar. Arahkan kursor ke ikon untuk melihat nama menu dan jumlah issue-nya. Pilihan ini diingat browser.

Pasang di HP

Aplikasi ini bisa dipasang seperti aplikasi biasa supaya cepat dibuka dari layar utama.

  • Android (Chrome): buka Settings → Install app, atau menu ⋮ → Install app.
  • iPhone (Safari): tombol Share → Add to Home Screen.

Alur update

Sync from Redmine

Menarik issue dari pjm.zahironline.com lalu menyimpannya sebagai Update Plan baru, tanpa perlu menyalin URL satu per satu.

  1. Buka Update Plans, lalu klik Sync Redmine.
  2. Pilih Project, Status Filter (biasanya Resolved atau Ready for Testing), dan Date range.
  3. Klik Preview untuk melihat daftar issue. Issue yang sudah pernah masuk plan ditandai Already added.
  4. Klik Sync Now. Issue baru tersimpan sebagai plan dengan tanda Redmine.
Hindari pilihan tanggal All kecuali benar-benar perlu: semua issue di project ikut ditarik dan prosesnya lama. Kalau ragu koneksinya jalan, klik Test Connection dulu.

Update Plans

Satu plan berisi daftar issue untuk satu rilis di satu lini produk (Zahir ERP, Zahir ERP One, Manufacturing, atau MRP).

  1. Klik Add New Plan (atau tekan N).
  2. Isi Title, Date, dan Project.
  3. Di SDET Issue List, tempel satu URL issue per baris. Nomor issue terdeteksi otomatis, deskripsi boleh dikosongkan.
  4. Klik Save Plan.

Di daftar plan, kartu bisa dibuka untuk melihat isinya. Gunakan kolom pencarian (/), filter project, urutan terbaru/terlama, serta chip No summary, Has summary, dan Redmine untuk menyaring.

Update Summaries

Ringkasan rilis yang siap ditempel ke grup WA atau Telegram, dibuat dari sebuah Update Plan.

  1. Klik Add New Summary, lalu pilih Update Plan-nya.
  2. Isi FE Version, V2 Version, V3 Version (opsional), dan Release Date.
  3. Pilih template WA formal, WA singkat, atau Telegram, lalu klik Auto-generate. Issue dikelompokkan otomatis berdasarkan jenisnya (bug, enhancement, dan sebagainya) dengan membaca tracker di Redmine.
  4. Sunting hasilnya bila perlu, atau tempel hasil GPT kamu sendiri, lalu klik Save Summary.
Plan yang belum punya summary muncul di kartu Needs Summary di Dashboard.

Membagikan plan

Tombol copy di setiap kartu plan menyediakan beberapa format sekaligus:

Share link
Link pendek read-only yang bisa dibuka siapa saja tanpa login. Cocok untuk SDET.
Telegram (links only / link + desc)
Nomor issue menjadi link yang bisa diklik di Telegram.
Markdown
Untuk Slack atau Discord.
Numbered list
Untuk WhatsApp, yang tidak mendukung markdown.
Plain URLs
Daftar URL polos untuk catatan atau backup.

Memantau issue

Dashboard

Halaman pertama yang merangkum semuanya: total plan, summary, dan issue; jumlah issue baru per project; serta Needs attention today, yaitu issue Immediate yang masih New, issue On Progress yang tidak bergerak lebih dari 7 hari, On Deploy, Rework, dan Feedback.

Klik kartu mana pun untuk langsung membuka daftar issue di baliknya.

Tester Queue

Daftar issue berstatus Ready for Testing dari Zahir ERP, Zahir ERP One, dan Manufacturing, dibagi per kategori: Front End, Backend, Design, dan Other. Kategori dibaca dari field Category di Redmine.

  • Saring dengan pencarian, project, dan prioritas; kelompokkan per project, assignee, atau prioritas.
  • Titik merah di sidebar menandakan ada issue RFT baru sejak terakhir kategori itu dibuka.
  • Copy list menyalin daftar siap tempel untuk briefing tester.

Issue Status

Lima menu di bawah Issue Status menampilkan issue per tahap kerja: New, On Progress, On Deploy, Rework, dan Feedback, gabungan dari ketiga project Zahir. Angka di sidebar menunjukkan jumlah issue di tiap tahap.

Kalau nama status di Redmine berbeda, ganti lewat pilihan Status di toolbar. Copy all links menyalin semua link issue yang sedang tampil.

Active Work

Siapa sedang mengerjakan apa. Menampilkan issue In Progress dan On Deploy, dikelompokkan per assignee secara default, sehingga beban kerja tiap orang terlihat sekilas.

Menu ini belum punya tombol di sidebar. Buka lewat tombol Buka Active Work di atas.

What Next

Mengurutkan issue New dari yang paling perlu dikerjakan lebih dulu. Skornya dihitung dari prioritas (Immediate paling tinggi), lama issue menunggu, dan apakah issue belum punya assignee. Alasan skornya ditampilkan di setiap baris.

  • Copy top list menyalin daftar teratas untuk dibahas di rapat.
  • Create plan from top membuat Update Plan baru dari issue teratas.

By Client

Mencari semua issue milik satu klien berdasarkan field Client Name di Redmine. Ketik nama klien, tekan Enter, lalu hasilnya dikelompokkan per status.

Filter & pilih banyak

Semua daftar issue memakai kontrol yang sama:

Chip cepat
All, Immediate, Unassigned, dan Updated 7d untuk menyaring dengan sekali klik.
Kepadatan
Comfortable atau Compact, untuk melihat lebih banyak baris sekaligus.
Pilih banyak
Centang beberapa issue, lalu gunakan bar di bawah layar untuk Copy links atau Copy for Telegram.

Filter yang kamu pakai diingat, jadi tetap sama saat halaman dibuka lagi.

Alat bantu

New Issue

Membuat issue baru langsung di Redmine tanpa membuka Redmine.

  1. Pilih Project, lalu Tracker, Priority, dan Category (pilihan dimuat dari Redmine).
  2. Tulis Subject, misalnya FE - Error when saving Purchase Order. Awalan FE, BE, atau DE membantu pengelompokan kategori.
  3. Tulis poin singkat di Notes for description generator, lalu klik Generate description untuk menyusun deskripsi lengkap.
  4. Periksa deskripsinya, lalu klik Push to Redmine. Link issue baru langsung ditampilkan.

Knowledge Base

Tempat tim menulis cara pemakaian fitur Zahir ERP, ERP One, Manufacturing, dan MRP, supaya semua orang support menjawab klien dengan langkah yang sama. Panduan tersimpan di workspace, jadi langsung terlihat oleh semua anggota tim.

  1. Klik Tulis panduan, lalu isi judul, produk, dan modul (mis. Penjualan, Persediaan).
  2. Isi langkah-langkahnya. Template awal sudah berisi Tujuan, Sebelum mulai, Langkah-langkah, dan Hasil.
  3. Tempel screenshot langsung dengan Ctrl+V, seret file gambar, atau klik Gambar. Gambar dikompres otomatis.
  4. Cek di tab Pratinjau, lalu Simpan panduan (atau Ctrl+S).

Saat membaca, Copy teks menyalin panduan dalam format yang rapi untuk WhatsApp, dan Copy link menyalin alamat langsung ke panduan itu untuk rekan tim.

Telegram & notifikasi

Pengaturannya ada di Settings → Telegram.

  1. Isi Chat ID grup atau channel tujuan, lalu klik Save. Chat ID harus sudah didaftarkan pemilik aplikasi di server; kalau belum, pengiriman akan ditolak.
  2. Send briefing mengirim ringkasan kondisi issue saat ini ke chat tersebut.
  3. Aktifkan Auto-notify agar Telegram diberi kabar setiap ada issue Ready for Testing baru, lalu coba dengan Send test RFT alert.

Ikon lonceng di kanan atas menampilkan riwayat alert dan bisa mengaktifkan notifikasi browser. Selama tab aplikasi terbuka, issue RFT baru dicek kira-kira tiap 90 detik. Saat tab tertutup, server tetap mengecek sekali sehari pukul 09.00 WIB.

Pencarian & Notes

Ikon kaca pembesar di kanan atas membuka pencarian global yang mencari sekaligus di plan, issue, klien, dan catatan. Klik hasilnya untuk langsung menuju lokasinya.

Notes adalah catatan cepat untuk pengingat pribadi. Catatan ini tersimpan di browser perangkat yang dipakai, bukan di cloud. Notes tidak ada di sidebar; buka lewat pencarian global atau .

Data & bantuan

Backup & restore

Data plan dan summary tersimpan di cloud dan tersinkron otomatis. Status terakhirnya terlihat di Settings → Cloud Sync dan di pojok kiri bawah sidebar.

  • Export JSON mengunduh salinan semua data ke komputer.
  • Import JSON memulihkan data dari file backup tersebut.
  • Delete All Data menghapus semua plan dan summary di workspace aktif secara permanen.
Kalau sedang memakai workspace tim, Delete All Data juga menghapus data rekan setim. Lakukan Export JSON dulu sebelum menghapus.

Kalau ada masalah

Muncul "Sign-in required" atau "Not available in guest mode"

Fitur Redmine dan Telegram butuh login Google. Buka Settings → Sign in with Google.

Muncul "Account … is not allowed"

Email Google kamu belum didaftarkan di server. Minta pemilik aplikasi menambahkannya, lalu reload halaman.

Muncul "Chat ID not allowed" saat kirim Telegram

Chat ID di Settings berbeda dengan yang didaftarkan di server. Samakan Chat ID-nya, atau minta pemilik aplikasi mendaftarkan chat tersebut.

Plan di HP berbeda dengan di laptop

Pastikan kedua perangkat login dengan akun Google yang sama dan berada di workspace yang sama (cek Settings → Team Workspace).

Notifikasi RFT tidak datang saat tab ditutup

Saat tab tertutup, pengecekan dari server berjalan sekali sehari pukul 09.00 WIB. Untuk kabar yang lebih cepat, biarkan tab aplikasi tetap terbuka.

Tampilan belum berubah setelah update

Reload halaman sekali. Versi aplikasi terlihat di pojok kiri bawah sidebar dan di Settings → What's New.
